## 📌 About the Project

This repository contains my personal developer portfolio, designed and developed to showcase my technical skills, projects, achievements, and learning journey.

The portfolio focuses on a clean, interactive, and visually engaging experience while maintaining a professional developer identity.

## ✨ Features

- **Personal Introduction** – Overview of my background and interests.
- **Skills Showcase** – Technologies and tools I work with.
- **Project Gallery** – Highlights of my development projects.
- **Education Timeline** – Academic background and journey.
- **Interactive Animations** – Custom butterfly animation and smooth scrolling interactions.
- **Contact Section** – A form for visitors to get in touch.
- **Responsive Interface** – Designed to provide a smooth browsing experience across screen sizes.
